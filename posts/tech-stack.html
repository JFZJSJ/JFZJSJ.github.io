我的技术栈与下半年学习路线

2026-08-20 ·
技术 学习

每过一段时间，我都会把自己的技术栈摊开来看一遍，顺便想想接下来该学什么。 整理本身也是一种学习：它逼你诚实地面对「我会什么」和「我其实不会什么」。

日常在用的

领域 工具 / 语言 熟练度
前端基础 HTML / CSS / JavaScript ★★★☆☆
脚本工具 Python ★★★☆☆
版本管理 Git ★★☆☆☆
命令行 Bash / PowerShell ★★☆☆☆

「熟练度」是很主观的打分，但诚实打分比虚假的自信有用得多。

下半年想做的几件事

  1. 把 JavaScript 的异步彻底吃透：Promise、async/await、 事件循环，不满足于「能用」，要能讲清楚原理。
  2. 学一点 Node.js：写几个自动化小脚本，把重复劳动交出去。
  3. 用这个博客做实验：比如给文章加搜索、加暗色模式开关。
  4. 坚持每月至少两篇博文：写作是思考的磨刀石。

一个小的练习建议

学任何新东西，最怕「收藏了就等于学会了」。我的办法是，学完立刻写一个 最小的可用例子，比如这样：

// 读一个文件并统计行数（Node.js）
const fs = require('fs');
const text = fs.readFileSync('note.md', 'utf-8');
const lines = text.split('\n').filter(Boolean);
console.log(`note.md 共有 ${lines.length} 行非空内容`);

能跑通、能解释每一行在干什么，才算真正「过了一遍脑子」。

学习的终点不是「我看过」，而是「我能做出来」。

目标不多，重在落地。半年后再回来对照这份清单，看看完成了多少。
